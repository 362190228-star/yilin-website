# 蔡艺琳的个人日记本 · Portfolio Notebook

一个日记本 / 手帐本风格的个人作品集网站。打开网站先看到一本合上的日记本平铺在桌面上，
点击封面后翻开，通过翻页方式浏览「个人介绍 / 实习经历 / 个人作品 / 兴趣爱好 / 联系我」五个页面。

## 一、如何启动项目

需要先安装 [Node.js](https://nodejs.org/)（建议 18 及以上版本）。

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器（默认 http://localhost:5173）
npm run dev

# 3. 生成生产构建（输出到 dist/ 目录）
npm run build

# 4. 本地预览生产构建
npm run preview

# 5. 代码检查（可选）
npm run lint
```

打开 `npm run dev` 给出的地址即可在浏览器里看到效果。

## 三、哪些位置可以替换照片和作品图片

**所有图片都用的是 `public/placeholders/` 目录下的 SVG 占位图**，命名规范，替换时直接用
同名的真实图片文件覆盖即可（保持文件名不变，或改文件名后同步修改对应 data 文件里的路径）：

| 位置 | 占位文件 | 对应数据文件 |
|---|---|---|
| 关于我 · 个人照片 ×3 | `about-1.svg` `about-2.svg` `about-3.svg` | `src/data/profile.ts` → `photos` 数组 |
| 兴趣爱好 · 生活照片 ×5 | `hobby-1.svg` ~ `hobby-5.svg` | `src/data/hobbies.ts` → `image` 字段 |
| 个人作品 · 每个项目 ×3 张 | `work-{1~6}-cover.svg`（封面）<br>`work-{1~6}-a.svg`（关键页面1）<br>`work-{1~6}-b.svg`（关键页面2） | `src/data/works.ts` → `cover` / `images` 字段 |

替换建议：
- 关于我的照片建议用**方形或接近方形**的图（拍立得样式会自动裁切成方形，不会变形）
- 作品封面建议用 **4:3** 比例，弹窗大图建议用 **16:9** 比例，这样不会被裁切变形
- 图片体积建议控制在 300KB 以内，加载会更流畅

## 四、哪些文案可以继续修改

全部集中在 `src/data/` 目录下的 5 个文件里，不需要碰组件代码：

- **`profile.ts`**：姓名、职位、教育背景、方向关键词（AI Agent / AIGC 等标签）、个人介绍文案、照片说明文字
- **`experiences.ts`**：公司名称、时间、方向、经历描述、标签
- **`works.ts`**：6 个项目的标题、分类标签、一句话简介（卡片上显示）、详细说明（弹窗里显示）
- **`hobbies.ts`**：5 个兴趣标题、一句话说明，以及页面结尾的感想文案
- **`contact.ts`**：结尾寄语、邮箱地址、简历/作品集链接、社交账号

此外，`src/App.tsx` 顶部的 `introContent` 数组是桌面端左页显示的「索引小结」文字
（每个主题一段引导性说明），如果想调整这部分文案也可以在这里改。

## 五、一些实现细节说明

- **翻页触发优先级**：点击左侧 tab / 页角按钮 > 键盘左右方向键 > 鼠标滚轮。滚轮做了节流
  （900ms 内只响应一次），避免触控板连续滚动导致一次跳好几页。
- **作品弹窗打开时**，背后日记本的翻页（tab、按钮、键盘、滚轮）会全部暂停，避免弹窗还开着
  的时候背景内容被切换，关闭弹窗后自动恢复。
- **双页布局逻辑**：桌面端（≥900px）每个主题占一组双页，左页是索引小结卡片，右页是主内容；
  移动端收起为单页，只显示主内容。
- **动效幅度**：翻页动画的旋转角度控制在 8 度以内、位移 24px 以内，刻意保持克制，避免游戏化的
  夸张 3D 翻书效果。
- 已适配 `prefers-reduced-motion`，系统开启「减弱动态效果」时动画会自动缩短。


## 纸张翻页交互

- 桌面端左右纸边各 64px，手机端各 56px；纸边之外保留内容阅读和作品点击。
- 悬停/键盘聚焦轻抬页角，220ms 回落；点击后执行 860ms 双面弯曲翻页。
- 方向键、边缘点击、章节索引共用动画锁；首尾不循环，滚轮只滚动内容。
- 移动端横向滑动：至少 56px，水平距离大于纵向距离的 1.8 倍；同时满足距离至少 96px 或速度至少 0.45px/ms。
- 纵向阅读、多指触摸、手势取消以及作品弹窗打开/退出期间禁止翻页。
- 首次内页展示一次页角提示；减少动态效果偏好下直接切换，禁用提示。

验证：`npm run build`、`npm run lint`、`npm test`（测试需 Node.js 22.18+）。
